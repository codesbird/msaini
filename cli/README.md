# tech2saini 🚀

> Monu Saini's Interactive Terminal Resume & Developer Card

Run directly in any terminal without manual installation:

```bash
npx tech2saini
```

Or connect directly with role filtering:

```bash
npx tech2saini --connect --role=python-sde
```

---

## ⚡ Command Line Options

| Flag | Shorthand | Description |
|---|---|---|
| `--connect` | `-c` | Display direct contact channels (Email, Phone, LinkedIn, GitHub) |
| `--role=python-sde` | | Filter overview for Python Backend SDE competencies |
| `--role=ai-engineer`| | Filter overview for AI Agents, n8n, and MCP workflows |
| `--json` | `-j` | Output full resume data in machine-readable JSON |
| `--help` | `-h` | Display usage instructions and available options |
